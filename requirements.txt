# environment" was not a true statement about this repository, and that is a
# claim the paper makes. Pinned 2026-08-21.
#
# Machine of record: python 3.11.9, numpy 1.26.4.
# env_hash in every results/*.json is a hash over {python, numpy, ...}, so
# changing either value intentionally will change every recorded hash. That is
# correct behaviour, not a failure. If you deliberately move the pin, re-run
# `bash verify.sh && python3 scripts/dry_run.py` and commit the regenerated
# artifacts in the SAME commit as the pin change, so the two never disagree.
